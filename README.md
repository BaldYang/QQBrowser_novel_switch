## 使用说明v2.0.0
更新时间：*`2026/11/01`*  
作者：*`Mr. Measure`*
### 一、简介
该软件基于iApp制作，用于提取转换QQ浏览器中已下载的小说文本，QQ浏览器中下载的小说文本为网页文件，直接阅读体验不佳，该软件将此文本进行分段、截取，转换出可阅读的txt文本，并进行合并，可用于导入部分阅读器查看或直接查看。
### 二、使用方法
#### 1.下载QQ浏览器小说（如已下载可忽略此步）
打开QQ浏览器—点击导航栏“`小说`”—搜索小说并打开—点击右上角“`下载`”—观看广告（或开通悦读卡）—开始下载并完成。
#### 2.下载并启用Shizuku服务（Android 10及以下系统忽略此步，仅需授予存储权限即可）
打开「QQ浏览器小说文本转换器」首页或点击左下角“`检索已下载的小说`”按钮—点击“`前往下载Shizuku`”（如已下载请跳转至第二行）  
下载安装完成后打开Shizuku—点击“`配对`”—点击“`通知设置`”—点击“`允许通知`”—回到Shizuku点击“`开发者选项`”（打不开可前往系统设置—关于手机—连续点击7次“版本号”即可（不同手机型号操作可能略有差异））  
在开发者设置中打开“`USB调试`”和“`无线调试`”—点击无线调试中的“`使用配对码配对设备`”—记住WLAN配对码并下拉打开通知栏—点击“`Shizuku已找到配对服务`”右侧下箭头—点击“`输入配对码`”—输入刚刚的WLAN配对码—点击右侧的发送小箭头—配对成功后打开Shizuku首页—点击“`启动`”  
https://shizuku.rikka.app/zh-hans/guide/setup/ 相关问题可打开此链接，点击“`常见问题`”查找解决方案；HarmonyOS 3和HarmonyOS 4用户如有能力可使用“`通过连接电脑启动`" 启动Shizuku（HarmonyOS 5及以上不支持）
#### 3.小说文本提取、转换、合并、分享
打开「QQ浏览器小说文本转换器」首页—点击左下角“`检索已下载的小说`”按钮—点击每本书后面的“`转换`”按钮—等待转换完成。  
已转换成功的小说文本路径（已合并）：“`/storage/emulated/0/QQBrowser_novel_switch/novel/xxx(“已完结”或“连载中”)/xxx.txt/`”  
点击“`分享`”按钮可分享小说文件或用其它阅读器打开。

#### 1.打开方式
打开「QQ浏览器小说文本转换器」首页—进入主页—点击右上角设置图标（长按可打开QQ浏览器）。
